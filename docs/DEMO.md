# Demo Script — Three Minutes

## 0:00–0:20 — The Problem
"Smart contracts can verify that money arrived. They cannot decide whether creative work matched a human brief."

## 0:20–0:55 — Forge
Open `/forge`. Enter:
> "Pay 1.5 GEN for a responsive launch page with our logo, hero, three feature cards, pricing, and a contact link before Sunday."

Show the Forge splitting it into criteria with validator tests and failure boundaries.

Key line: **"Consensus freezes the meaning before it freezes the money."**

## 0:55–1:20 — Fund and Accept
- Fund with MetaMask on StudioNet
- Open second wallet (or pre-prepared agreement)
- Worker accepts the frozen terms

## 1:20–1:45 — Submit
Worker submits a public deployed page URL and a summary.

## 1:45–2:30 — Ask Consensus
- Trigger adjudication
- Show real transaction states: Submitted → Pending → Accepted
- Explain: leader proposes, validators evaluate independently

## 2:30–2:50 — Verdict
Show criterion-by-criterion results. Worker claims payout.

## 2:50–3:00 — Vision
"Today it judges freelance delivery. Tomorrow the same agreement primitive coordinates humans, DAOs, and autonomous agents."
